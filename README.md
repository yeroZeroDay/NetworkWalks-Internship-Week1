Cybersecurity Journey: Week 1 Project Completed!

I’m pleased to share that I’ve successfully completed my first hands-on project as part of the Cybersecurity Program at Networkwalks (Batch B084).

Week 1: Building a Cybersecurity & Penetration Testing Lab

The primary objective of this project was to establish a virtual environment for cybersecurity experimentation and penetration testing using Oracle VirtualBox and Kali Linux.

 Key Tasks Accomplished:
- Installed and configured VirtualBox for virtualization.
- Imported and set up the Kali Linux virtual machine.
- Created a private NAT Network for virtual machine communication.
- Configured and tested Kali Linux network settings.

 Key Takeaways:

This practical exercise strengthened my understanding of virtual machine networking, the differences between NAT and NAT Network, and IP address configuration.

This is just the beginning of my cybersecurity journey, and I look forward to building more practical skills, exploring new security tools, and deepening my knowledge of penetration testing.
